# Reconstruction Dossier — Token Recursion Engine

## Decision
**SOFTWARE/RUNTIME COMPONENT FIRST; SIGMA IDENTITY NOT YET JUSTIFIED.**

## Reconstructed architecture
1. Local layered concept store.
2. External-store adapter.
3. Retrieval order.
4. Provenance-bearing result object.
5. Explicit synthetic fallback.
6. Optional cache of external results.

## Deferred research modules
- semantic cluster detector;
- recurrence/stability metric;
- adaptive computation-depth controller;
- conflict/uncertainty estimator;
- benchmark harness.

## Benchmark required before capability claims
Compare at least:
A. no retrieval memory;
B. flat cache;
C. layered cache;
D. layered + external retrieval;
E. layered + explicit fallback.

Measure retrieval accuracy, provenance accuracy, stale-record rate, false reconstruction rate, latency and task performance. Preserve raw answers before scoring.

## Constitutional route
If a mathematically distinct operator emerges—for example a governed adaptive-depth rule—it may later be proposed as a Sigma candidate. Software modules themselves do not receive canonical admission by default.
